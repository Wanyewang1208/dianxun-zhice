# data · 公共、示例与处理后数据

## 职责
作为跨模块可共享数据的协作入口。目前没有复制前端场景数据，前端演示来源仍是 `frontend/src/data/demoBattery.ts`，避免出现两份不一致的数据。

## 推荐文件
后续可建立 `public/`（可公开且有授权的数据）、`examples/`（小型示例）、`processed/`（可复现的处理后数据）及字段字典。每个数据集附来源、授权、日期、版本、单位、处理方法和真实/合成标记。

## 不应该放
个人或车辆敏感数据、密钥、无授权数据、依赖和缓存。大型原始数据不直接提交 Git；先约定外部存储或 Git LFS，并提供获取/生成说明。当前不以宽泛的 CSV/JSON 忽略规则排除必要示例数据。

## 对接约定
供 `model/`、`carbon/`、`backend/` 使用。字段或单位变更先更新 `docs/`，同步使用方；提供生成脚本以复现 processed 数据。将来若迁出前端场景数据，必须同时调整导入并验证场景联动。

## V0.3 模块接入

# 数据范围与版本

- sample/bms：原表头模板和明确标记 synthetic_fixture 的质量检查用例。
- processed：公开 NASA 电芯处理后特征/容量；完整包另有压缩实验时序。
- demo：示例路径配置、碳/健康/寿命/SHAP 等已保存实验结果，均非真实车辆商业检测结果。
- versions/manifest.json：V0.1、V0.2 历史数据索引，记录原始路径、版本、当前打包位置与 SHA256。内容相同只保存一份；有差异则保存在对应版本目录。CSV/JSON 为历史数据结果，gz 为处理后时序，不含原始 MAT 下载副本。

本包实际模型使用 NASA B0005/B0006/B0007/B0018。CALCE 仅属于项目可能采用的公开验证数据来源，本包未新增/声称包含 CALCE 数据。公开 NASA/CALCE 电芯验证不能直接等同于真实车辆 BMS 验证。

原数据说明见 docs/v03/DATA_CARD.md。原始数据为按需下载复现，不打入本次合并包；未包含真实车主、VIN 或车辆位置数据。docs/v03 与 docs/v03_integration 是历史资料，路径可能保留旧版写法；当前路径和命令以 MERGE_GUIDE、API_CONTRACT 和 integration_guide 为准。
