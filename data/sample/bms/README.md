# 电循智策 BMS数据需求清单 V0.1

正式字段字典为 `电循智策_BMS数据需求清单.csv`，分必须、强烈建议、可选三级。优先级针对未来真实车用电池评估场景，不意味着当前公开电芯基线用到了全部字段。采样频率是项目建议，不是对车厂接口能力或标准要求的承诺。

可用Excel直接打开CSV。模板是空表，仅有表头，没有虚构车主或车企记录。按 metadata、telemetry、全部单体电压、温度探针、故障/维修事件和容量检测分表接入；用脱敏 battery_id 关联，用含时区时间戳对齐。优先获取数个电池ID的连续原始片段及采样/单位说明，先评估缺失率、信号可得性、协议和标签，再决定可用模型。

电流统一“放电正、充电负”，保留原始符号说明。NASA实验放电负，与模板不同；本次模型保留NASA原始符号，因此不能直接把模板整包数据输入实验电芯模型。未知字段留空，不能填0；诊断无故障可填明确的无故障编码或空数组，与未采集区分。cell_index和probe_index建议从1起且长期保持位置映射。

## 数据取得路径与当前缺口

1. 当前已经取得NASA四个公开实验电芯的电压、电流、单点温度、放电容量及实验序号。没有取得真实车辆的SOC、里程、整包单体分布、绝缘、故障或车厂SOH，也没有接入车企BMS。
2. 下一步可向学校电池实验室或检测机构申请匿名历史检测数据和容量测试规程；向愿意合作的车主及检测机构申请授权导出。尚未联系、尚无合作承诺。普通OBD设备能否取得全部字段取决于车型、协议和授权，不能预先保证。
3. 要求对方先提供字段目录、单位/符号、频率、缺失编码、时间范围、电池更换记录及是否允许用于研发。先验证一段数据的完整性，再扩大样本；不要求明文VIN、精确定位和车主个人信息。
4. SOH监督训练需要独立容量测试标签及测试条件。SOH_BMS仅可作为对照或噪声标签研究，不能直接包装为独立真实容量。RUL需要多电池长期退化和实际EOL观测，几段充电记录不足以证明寿命预测能力。

本版基线用于离线方法验证，不输出真实电池的安全放行、交易定价或强制退役结论。
