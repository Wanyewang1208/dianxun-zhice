# 真实数据验证准备（尚未联系或取得合作）

先从学校电池实验室、具备授权数据导出能力的检测机构或愿意配合的维修/二手车机构询问字段可得性。现阶段不承诺能读出所有车型BMS，也不自动联系或发送消息。

第一轮可争取5–10个不同物理电池包的匿名片段，用来验证导出、单位、时区、缺失和模型输入是否可用。这个规模仅适合可行性检查，不足以证明商业化精度。没有独立容量测试标签时，只能作数据质量、运行特征和对照分析，不能报告真实SOH误差。

需要对方确认：数据授权用途及保留期限；脱敏电池ID是否稳定；是否发生换包；字段/单位/正负号；采样频率和丢包情况；车型与化学体系；测试工况；是否有独立容量检测及其仪器/规程。无需明文VIN、个人身份或精确定位。

接收时同时填写bms/metadata_v02_template.csv和telemetry_template.csv，运行BMS检查，保存源文件哈希和问题清单。按物理电池ID拆分开发和留出集，在首次看留出结果前冻结模型及指标。新车/旧车、不同体系或测试方法不可混成一个未经解释的平均误差。

建议分三关：

1. 字段可得性：核心信号齐全且时间/单位明确，否则先修采集。
2. 标签可比性：有独立容量测试，记录截止电压、倍率、温度；SOH_BMS仅作为对照。
3. 泛化性：按从未用于开发的电池包ID留出；不将NASA电芯特征直接当成整包模型。

RUL另需长期追踪和实际终点观测，不能凭几段充电数据替代。真实安全决策需专业检测证据、适用产品标准和审批责任人，本版模拟策略不可直接上线。
