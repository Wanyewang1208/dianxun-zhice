# RUL方法 V0.2：探索性跨电芯对比

本版沿用NASA FY08Q4原始数据和README的额定2Ah、EOL=1.4Ah定义。原数据不变，V0.1结果不重写。记录中的cycle是放电操作序号，不是等效满循环、日历寿命或车辆里程。B0007未跨阈值，保持右删失。

## 诊断和输入

B0005第34循环局部斜率约-0.000188Ah/循环，原趋势法外推2228循环，真值91循环。此方法对接近零的斜率非常敏感。保留原误差，不通过事后截断上限改变基准分数。

每个预测时点需要从首测到当前的容量历史，并至少有30次容量观测。特征为当前循环、当前容量、首测容量、累计容量变化、最近30次容量的均值、标准差和线性斜率。特征提取先截取截至当前时点的前缀，再计算统计量，不全序列平滑。容量来自诊断测试，不是上一版SOH模型预测。

## 三种新增方法

1. 训练电芯速率：每颗训练电芯只取首次EOL前及该点的容量轨迹，拟合线性退化速率。取电芯速率中位数。预测为当前容量距1.4Ah的差额除以参考速率。完整训练寿命可用于训练，测试电芯未来寿命不可输入。
2. 速率融合：本电芯最近30次局部退化速率与训练参考速率各占50%；局部非退化速率按0处理，避免负退化率。所有权重固定，不基于测试结果调节。
3. 随机森林：300棵树、最大深度4、叶节点最少8条、种子42，以剩余循环标签监督训练。每颗训练电芯的总样本权重相等，减少寿命长的电芯占主导。预测为树的均值，没有声称带置信区间。

## 评估协议

对B0005/B0006/B0018做3折留一电芯验证，每折用其余2颗已观测终点电芯。B0007不进入任何监督训练；单独由3颗终点电芯训练后生成删失电芯预测，不计算其MAE、RMSE、R²。所有方法使用相同的第30循环至首次EOL之前的时点，不计终点及终点后的平凡零RUL样本。EOL用于离线标签和评估样本定义，不进入特征。

macro_metrics.csv对3个测试电芯的指标等权平均，不将241个相关时间前缀当作241颗独立电池。metrics_by_cell.csv保留逐颗结果；predictions.csv可独立复算。训练模型和实际训练ID保存在models/rul_v02，全部参数配置见protocol.json。

原实验只包含3颗观测终点电芯；V0.1已查看过这些数据，因此严格称“相同数据集上的探索性改进”，不称新增独立测试。固定参数可减少测试集调参，但不能撤销此前的数据查看。标准协议下共同循环进度和相近寿命也有助于预测，不能将改进全部归功于复杂模型。

下一步需要全新未参与开发的电芯数据、多温度/倍率工况、日历老化以及独立容量标签。尚未实现删失生存模型、端到端BMS-RUL、经校准置信区间或实车验证；不支持真实车辆剩余年份和里程承诺。
