# backend · 接口服务

## 职责
后续承接前端评估请求，校验输入、组织 SOH/RUL 与碳核算服务，返回一致的评估结果。已接入 V0.3 本地原型 API；真实车辆端到端验证尚未完成。

## 推荐文件
后续可放 `src/`、路由、请求/响应类型、配置示例、依赖清单及 `tests/`。技术框架由团队确认后再初始化。

## 不应该放
前端组件、模型训练数据、模型大权重、密钥、真实用户资料、虚拟环境和运行日志。

## 对接约定
先在 `docs/` 定义接口与错误码，再由前端接入；调用 `model/` 的推理入口、`carbon/` 的核算入口，引用 `data/` 中经确认的数据版本。约定 battery ID、输入单位、缺失字段、模型版本、来源、风险与演示标记，不将失败伪装成正常结果。

## 启动与对接

仓库根目录执行 `py -3.12 scripts/start_backend.py`。接口地址 `http://127.0.0.1:8013/api/v1/assessment`。

详见 [接口契约](../docs/API_CONTRACT.md)、[联调说明](../docs/integration_guide.md)、[本次合并记录](../docs/v03-repository-integration.md)。
